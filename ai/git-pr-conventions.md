# Git PR Conventions

Branch: `PIN-{Worki_ID}/{name-description}`

- **Worki_ID** — the ticket number. Commits on this branch use that same id (`PIN-609/user-profile` → `PIN-609`). Commits on `develop` use `PIN-0`.
- **name-description** — short kebab-case name for the change

Examples:

PIN-42/prepare-code-repository
